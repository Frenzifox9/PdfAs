# FilsBox corrigé

1. Publie `index.html` sur GitHub Pages.
2. Dans Firebase, active Authentication > Email/Password.
3. Crée Firestore Database.
4. Dans Firestore > Rules, colle `firestore.rules` puis clique Publish.
5. Utilise le même pseudo et mot de passe sur chaque appareil.

Pas besoin de Firebase Storage dans cette version. Les fichiers doivent faire moins de 650 Ko pour tenir dans un document Firestore. La synchronisation nécessite Internet.
